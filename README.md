# m3eui

**English** | [简体中文](./README.zh-CN.md)

**Material 3 Expressive (`1.5.0`) Web React component system, declarative `m3e.json` CLI, and cross-platform mathematical token engine.**

Built on `@base-ui/react` (`1.9.0`) headless accessibility primitives, pure TypeScript HCT color and spring physics (`m3eui/tokens`), `shadcn/ui`-inspired `m3e.json` project configuration (`m3eui`), 100% key-driven internationalization with automatic RTL mirroring, and native semantic CSS (`light-dark()`) with zero Tailwind dependencies.

---

## Workspace Architecture (`v0.1.0` — All-in-One `m3eui`)

| Target | Path | Description |
| :--- | :--- | :--- |

| **`m3eui-playground`** | `apps/playground` | Self-hosted interactive documentation & theme studio built 100% with `m3eui` components. |

## Installation

Install **only one package** — components, tokens, styles, and the `m3eui` CLI are all included:

```bash
# pnpm
pnpm add m3eui

# npm
npm install m3eui
```

Peer dependencies: `react >= 18.0.0`, `react-dom >= 18.0.0`.

## Quick Start

### 1. Initialize `m3e.json` and Static Theme CSS

Generate a declarative `m3e.json` file and compile zero-JS-flash `:root` CSS custom properties (`light-dark()` + `linear()` spring timing variables):

```bash
npx m3eui init --seed "#6750A4" --variant expressive --locale en-US
```

Example `m3e.json`:

```json
{
  "$schema": "https://unpkg.com/m3eui@0.1.0/m3e.schema.json",
  "style": "expressive",
  "theme": {
    "seed": "#6750A4",
    "schemeVariant": "expressive",
    "colorMode": "system",
    "contrastLevel": 0,
    "motionScheme": "expressive"
  },
  "i18n": {
    "locale": "en-US",
    "direction": "auto"
  },
  "css": {
    "output": "src/styles/m3e-theme.css"
  }
}
```

### 2. Mount `M3EProvider` and Components

```tsx
import "./styles/m3e-theme.css"; // Static theme CSS generated by `m3eui sync`
import "m3eui/styles.css";      // Core component stylesheet
import {
  M3EProvider,
  NavigationMenu,
  Collapsible,
  Button,
  Switch,
  TimePickerField,
} from "m3eui";
import m3eConfig from "../m3e.json";

export function App() {
  return (
    <M3EProvider
      config={m3eConfig}
      // Optional runtime key overrides on top of the active locale dictionary
      messages={{ "searchBar.placeholder": "Search components, tokens, or specs…" }}
    >
      <NavigationMenu
        brand="m3eui"
        items={[
          { value: "home", label: "Home", href: "/", active: true },
          {
            value: "docs",
            label: "Documentation",
            links: [{ id: "i18n", title: "i18n & m3e.json", href: "/docs/i18n" }],
          },
        ]}
      />

      <Collapsible title="Architecture Note (auto-expands on Ctrl/Cmd+F find-in-page)">
        Components contain zero hardcoded natural-language strings and mirror
        automatically when switched to RTL locales such as ar-SA.
      </Collapsible>

      <Button variant="filled">Save Changes</Button>
      <Switch label="Enable notifications" defaultChecked />
      <TimePickerField label="Release time" defaultValue="09:30" />
    </M3EProvider>
  );
}
```

### 3. Next.js App Router (Zero-FOUC Color Mode)

Place `<meta name="color-scheme" content="light dark" />` and `getM3EInitScript()` inside `<head>` so persisted user light/dark overrides apply synchronously before first paint:

```tsx
import "./styles/m3e-theme.css";
import "m3eui/styles.css";
import { M3EProvider, getM3EInitScript } from "m3eui";
import m3eConfig from "../m3e.json";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <head>
        <meta name="color-scheme" content="light dark" />
        <script dangerouslySetInnerHTML={{ __html: getM3EInitScript() }} />
      </head>
      <body>
        <M3EProvider config={m3eConfig}>{children}</M3EProvider>
      </body>
    </html>
  );
}
```

## CLI Workflow (`m3eui`)

Both `m3eui` and `m3e` binary aliases are installed by `m3eui`:

```bash
# 1. Initialize m3e.json and emit static theme CSS
npx m3eui init --seed "#0B6B58" --variant vibrant --locale zh-CN

# 2. Re-sync static CSS after editing m3e.json
npx m3eui sync

# 3. List built-in locales or scaffold a custom typed locale pack (78 keys)
npx m3eui locale --list
npx m3eui locale fr-FR --out src/i18n/fr-FR.ts

# 4. Validate m3e.json, static CSS freshness, and source CJK guards
npx m3eui doctor
```

## Internationalization & Automatic RTL

- **Zero hardcoded UI copy**: Every internal aria label, dialog action, calendar/clock prompt, table sort announcement, and empty state resolves through 78 strongly typed `M3EMessageKey` entries.
- **Built-in locale packs**: `en-US`, `zh-CN`, `ja-JP`, and `ar-SA`.
- **Automatic bidirectional mirroring**: When `i18n.direction` is `"auto"` (default), switching `locale` to an RTL script (`ar-*`, `he-*`, `fa-*`, `ur-*`) automatically updates Base UI `DirectionProvider`, logical CSS layout, asymmetric corner radii (e.g., `SplitButton`, `SideSheet`), and horizontal gesture/arrow axes.
- **Locale-aware formatting**: `DockedDatePicker`, `DateRangePicker`, `TimePicker`, and `DataTable` format dates, weekdays, day periods, and natural-sort strings via standard `Intl.DateTimeFormat` and `Intl.Collator(locale, { numeric: true, sensitivity: "base" })`.

## Core Design & Physics Architecture

1. **HCT Perceptual Color & Five-Tier Surface Containers**: Synthesizes light and dark schemes from any hex seed via Material Color Utilities (`expressive`, `tonalSpot`, `vibrant`, `neutral`) with continuous contrast control (`[-1, 1]`) and native CSS `light-dark()` variables.
2. **Dual-Track Spring Physics**:
   - **Spatial springs (`Spatial`)**: Underdamped ($\zeta = 0.6 \sim 0.8$) for geometry, position, corner morphing, and drawer/rail expansion — natural overshoot is physically permitted.
   - **Effects springs (`Effects`)**: Strictly critically damped ($\zeta = 1.0$) for color, opacity, and elevation — never overshoots `[0, 1]` bounds.
   - Automatic cross-platform conversion in `m3eui/tokens` across CSS `linear()`, Motion JS, Android `SpringForce`, Jetpack Compose `spring()`, and Apple `CASpringAnimation` / SwiftUI.
3. **Dynamic Corner Topology & Zero-Sum Neighbor Squeeze**:
   - Interactive controls morph corners on press/selection (`Button`, `IconButton` 5×3 width matrix, `SplitButton` optical offset, `ConnectedButtonGroup`, `Accordion` detached `[16,16,16,16]` neighbors, `OTPField` focused slot detachment).
   - `ButtonGroup` (`standard`) and `Carousel` preserve exact container width (`sum(widths) === constant`) so sibling expansion never causes parent layout reflow.
4. **35 Normalized `MaterialShapes` & Polar Wavy Progress**: Built-in AOSP `[0..1]` closed cubic Bézier polygons with real-time 1:1 morphing (`MaterialShapeView`, `Avatar`, `LoadingIndicator`, `Skeleton`) and integer-lobe polar wavy indicators (`WavyProgressIndicator`).
