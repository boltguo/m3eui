# M3E (`m3eui` + `m3eui/tokens` + `m3eui`) — AI Coding Assistant Skill Guide (v1.0)

Use this reference whenever generating, configuring, localizing, or modifying UI built on `m3eui`, `m3eui/tokens`, and `m3eui`.

---

## 1. Project Configuration (`m3e.json`) & Imports Contract

1. Configure project-wide theme seed, HCT variant, contrast level, spring motion, default locale, and automatic RTL in root `m3e.json` (manageable via `npx m3eui init`, `m3e sync`, `m3e locale`, and `m3e doctor`).
2. Import the static theme variables generated by `m3e sync` (optional zero-JS-flash optimization) and `m3eui/styles.css` **once** at the application root, then wrap the app in `<M3EProvider config={m3eConfig}>`.
3. Subpath exports available on `m3eui`:
   - `m3eui` — All 60+ components, hooks, config helpers, and i18n packs
   - `m3eui/styles.css` — Complete semantic M3E stylesheet (`light-dark()`, RTL logical properties, `forced-colors`, `prefers-reduced-motion`)
   - `m3eui/i18n` — `M3EMessages`, `zhCNMessages`, `enUSMessages`, `jaJPMessages`, `arSAMessages`, `createM3ETranslator`, `isRtlLocale`
   - `m3eui/config` — `defineM3EConfig`, `resolveM3EConfig`, `generateM3EStaticThemeCss`
   - `m3eui/primitives` — Compound `@base-ui/react` namespaces (`DialogPrimitives`, `SelectPrimitives`, `NavigationMenuPrimitives`, `CollapsiblePrimitives`, `CSPProvider`, etc.)
4. Do **not** add Tailwind utility classes to override M3E geometry or colors, and **never** hardcode UI copy inside reusable components — consume `--m3e-color-*` custom properties and `useM3EI18n()`.

```tsx
import "./styles/m3e-theme.css"; // Generated via `m3e sync`
import "m3eui/styles.css";
import { M3EProvider, Button } from "m3eui";
import m3eConfig from "../m3e.json";

export function RootLayout({ children }: { children: React.ReactNode }) {
  return <M3EProvider config={m3eConfig}>{children}</M3EProvider>;
}
```

## 2. High-Frequency Recipes

### A. Key-Based i18n, Dynamic Locale Switching & Auto-RTL
```tsx
import { useM3E, useM3EI18n } from "m3eui";

export function LocaleBar() {
  const { locale, setLocale, setDirectionMode, direction } = useM3E();
  const { t } = useM3EI18n();

  return (
    <div data-dir={direction}>
      <button onClick={() => { setDirectionMode("auto"); setLocale("zh-CN"); }}>中文</button>
      <button onClick={() => { setDirectionMode("auto"); setLocale("en-US"); }}>EN</button>
      <button onClick={() => { setDirectionMode("auto"); setLocale("ja-JP"); }}>日本語</button>
      <button onClick={() => { setDirectionMode("auto"); setLocale("ar-SA"); }}>العربية (Auto RTL)</button>
      <span>{t("searchBar.placeholder")}</span>
    </div>
  );
}
```

### B. Adaptive App Shell (`NavigationSuite` + `TopAppBar` + `NavigationMenu`)
```tsx
import { NavigationSuite, TopAppBar, NavigationMenu } from "m3eui";

const DESTINATIONS = [
  { value: "dashboard", label: "Dashboard", icon: <HomeIcon /> },
  { value: "analytics", label: "Analytics", icon: <ChartIcon />, badgeCount: 4 },
];

export function WorkspaceShell({ children }: { children: React.ReactNode }) {
  const [route, setRoute] = React.useState("dashboard");
  return (
    <NavigationSuite layout="auto" items={DESTINATIONS} value={route} onValueChange={setRoute}>
      <TopAppBar variant="medium-flexible" title="Workspace" subtitle="Material 3 Expressive" />
      <NavigationMenu
        brand="M3E"
        items={[
          { value: "overview", label: "Overview", href: "/overview", active: true },
          {
            value: "guides",
            label: "Guides",
            links: [{ id: "cfg", title: "m3e.json Config", description: "Theme & i18n", href: "/docs/config" }],
          },
        ]}
      />
      {children}
    </NavigationSuite>
  );
}
```

### C. Validated Form with Server Errors (`Form` + `Fieldset` + `TextField`)
```tsx
export function ProfileForm() {
  const [errors, setErrors] = React.useState<Record<string, string>>({});
  return (
    <Form
      errors={errors}
      validationMode="onSubmit"
      showErrorSummary
      onSubmit={(e) => {
        e.preventDefault();
        setErrors({ handle: "Handle is already taken" });
      }}
    >
      <Fieldset legend="Public Profile" description="Shown on team cards">
        <TextField
          name="handle"
          label="Handle"
          invalid={Boolean(errors.handle)}
          errorMessage={errors.handle}
          required
        />
      </Fieldset>
      <Button type="submit" variant="filled">Save changes</Button>
    </Form>
  );
}
```

## 3. Anti-Patterns to Avoid

| Anti-Pattern | Correct M3E Pattern |
| :--- | :--- |
| Hardcoding Chinese/English labels inside components | Route built-in labels through `useM3EI18n().t(key)` and override via `m3e.json` or `<M3EProvider messages={...}>` |
| Using `new Date("2026-11-12")` for calendar dates | Pass plain ISO strings (`"2026-11-12"`) to `DockedDatePicker`, `DatePickerField`, and `DateRangePicker` |
| Styling padding/borders or `display: none` directly on `[hidden="until-found"]` | Use `<Collapsible>` / `<Accordion>` which keep padding and borders on nested `.m3e-collapsible__content` wrappers |
| Disabling `<Button type="submit">` before validation runs | Keep submit enabled so `<Form>` validates fields, announces `role="alert"`, and focuses the first invalid input |
| Setting `aria-sort="none"` on unsorted table headers | Let `DataTable` manage `aria-sort` strictly on the active sorted `<th scope="col">` |
| Animating `opacity` or `background-color` with `fastSpatial` (`ζ = 0.6`) | Use `effects` tokens (`ζ = 1.0`) for color/opacity; reserve `spatial` springs for physical geometry |
